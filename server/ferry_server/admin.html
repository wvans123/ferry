提示词

模型每次收到的系统提示由几层拼起来。工作电脑上的 agent 自带的那层（包括工具说明）不在这里改，下面这些会接在它后面。

拼接顺序

1
agent 自带的系统提示
来自工作电脑上的 ferry，包括可用的工具和用法，以及项目里的 AGENTS.md
2
全局提示词
每次请求都会加上
3
项目提示词
只在对应项目里加上；项目名就是工作电脑上运行 ferry 的文件夹名
4
写摘要时的要求
只在上下文太长、需要压缩成摘要时加上

全局提示词

比如：回复用中文；改代码前先读文件；不要动测试数据。保存后下一次请求就生效。

项目提示词

工作电脑上用过的项目会自动列出来，也可以先填一个项目名。

写摘要时的要求

对话太长时 agent 会把前面的内容压缩成摘要。可以要求摘要保留什么，比如"保留所有文件路径和报错原文，用中文写"。

检查一下：模型实际收到的系统提示

脱敏

发给模型前，把命中的内容换成 [FERRY-XXXXXXXX] 这样的占位符；模型回复里出现占位符时，回到工作电脑前再换回原文。

敏感词

一行一个：公司名、项目代号、主机名、人名等。不区分大小写。

自动识别

按格式识别，不用一个个列出来。

自定义规则（正则表达式）

试一试

输入一段文字，看看按当前设置会替换成什么（还没保存的改动也算）。

调用记录

每一次发给模型的请求。只记大小、耗时和用量，不记对话内容；想检查提示词，到"设置"里打开详细记录。

设置

改完立即生效，并保存在数据文件夹的 server.toml 里。

外网地址

工作电脑访问这台服务端用的地址，比如 Cloudflare 上配的域名。用来生成概览页的登录命令。

服务端存不存对话

完整对话始终保存在工作电脑上。这里决定服务端留不留一份副本，用来让工作电脑每轮只传新增的部分。

环境变量 FERRY_SESSION_STORE 已设置，服务端重启后会以它为准。

联网：替工作电脑读网页和搜索

工作电脑的命令行上不了外网。打开后，agent 的 web_fetch（读网页）和 web_search（搜索）由这台电脑代为访问，只把文字传回去。这等于让工作电脑经这里访问外网、绕开公司网关对这些网址的检查：请先确认公司规定允许，最好只放行需要的网站。

发给模型的请求上限

超过时从最旧的工具输出开始删，保证请求不超过这个大小。0 表示不限。

详细记录

在内存里保留最近 20 次请求的系统提示和最后一条消息（脱敏后的样子），用来检查提示词有没有生效。不写磁盘，重启就没了。

开机自动启动

令牌

工作电脑用它登录。换新令牌后，工作电脑要重新 ferry login。

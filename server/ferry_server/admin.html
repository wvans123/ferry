可用的模型

models.toml

在这里加模型、改默认模型。保存时会先检查格式，写错了不会生效。Key 放在环境变量里，文件里只写变量名（api_key_env）。

外网地址

工作电脑访问这台服务端用的地址，比如 Cloudflare 上配的域名。只用来生成左边的登录命令。

服务端保存对话吗

完整对话始终保存在工作电脑上。这里决定服务端留不留一份副本。切换后，正在进行的对话下一轮会整段重传一次。

环境变量 FERRY_SESSION_STORE 已设置，重启后会以它为准。
